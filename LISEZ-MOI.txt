NOUVEAUTÉS

- Icônes Paramètres harmonisées en noir ; présentation générale conservée.

IMPORTANT : LA CONVERSION WEB → PDF N'EST PAS ACTIVE PAR DÉFAUT.
Le dossier cloudflare-worker/ contient le code source d’un prototype Cloudflare Browser Rendering.
Il faudra créer un compte Cloudflare, déployer ce Worker, puis indiquer son URL HTTPS
dans Paramètres → Conversion Web → PDF. Ce prototype n’a pas été testé en conditions
réelles avec Marmiton ni le Journal des Femmes. Certains sites peuvent refuser
les navigateurs automatisés. L’URL originale est toujours conservée.

La V3 utilise volontairement une nouvelle base IndexedDB (mesrecettes-v3).
Les données V2 ne sont pas migrées : c’est conforme à la phase de tests.
Les recettes et leurs fichiers restent locaux sur l’iPhone, sauf l’URL transmise
à Cloudflare pour une conversion demandée explicitement.
