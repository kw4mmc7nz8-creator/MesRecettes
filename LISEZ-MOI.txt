MesRecettes V2 — 21 novembre 2026

INSTALLATION : copier le CONTENU de ce dossier à la racine du dépôt GitHub Pages (remplacer les anciens fichiers). Ne pas supprimer les données Safari.

Compatibilité : base IndexedDB « mesrecettes-v1 » conservée, migration de schéma version 1 vers 2, recettes existantes conservées.

Nouveautés : catégories modifiables, catégorie Légumes, commentaires facultatifs, boutons sources renommés, partage avec icône, sauvegarder/restaurer regroupés, retour réduit, sauvegardes ZIP comprenant les catégories et les commentaires.

IMPORTANT : sur un site tiers, une application statique GitHub Pages ne peut pas garantir une conversion automatique PDF. Le bouton Page Web → PDF conserve le lien et explique comment importer le PDF depuis Safari. Aucune conversion automatique universelle n'est revendiquée.

AVANT LA MISE À JOUR : depuis la V1, faites une sauvegarde complète et vérifiez qu'elle se trouve dans Fichiers. Après installation, tester les recettes existantes, les photos, les PDF et la restauration sur un appareil de test si possible.

L’icône Légumes utilise provisoirement un pictogramme 🥦 : le dessin exact choisi dans la conversation n’est pas présent dans l’archive V1.
